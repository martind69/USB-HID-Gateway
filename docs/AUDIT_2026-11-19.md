# Audit after successful build

Corrected by this overlay:

1. Default and production presets now consume `sdkconfig.defaults`; verbose consumes the correctly named `sdkconfig.defaults.verbose`.
2. `dependencies.lock` is no longer ignored.
3. The SSD1306 display now actually calls the completed 5x7 renderer.
4. SD is mounted before profile/cache/log access; optional boot capture is honored.
5. The self-test waits for correlated STATUS and no longer double-counts TX metrics.
6. S3 now compiles `s3_proxy_reports.c`, initializes the proxy queue, and runs a real SPI slave transaction loop.
7. S3 uses `CONFIG_TINYUSB_HID_COUNT=1`, not the obsolete `CONFIG_TINYUSB_HID_ENABLED`.

Remaining evidence-dependent work:

- exact G815/G502 report descriptors and Logitech vendor traffic;
- actual S3 TinyUSB G815 endpoint implementation; current `usb_device.c` in the supplied tree is a stub;
- P4 physical-host SET_REPORT/GET_REPORT/control callbacks are not registered with `usb_proxy_control`;
- `usb_proxy_descriptor.c/.h` remains a placeholder;
- `usb_proxy_transport.c` still contains obsolete NOT_SUPPORTED reverse stubs and should be collapsed into `usb_proxy_control` after host callback integration;
- old compressed one-line modules should be formatted, but successful `-Werror` build confirms syntax and warning cleanliness for the active configuration.
